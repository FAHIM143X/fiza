## 🚂 Deploy on Railway

1. Click **Deploy on Railway** above.
2. Sign in to Railway.
3. Connect your GitHub account if requested.
4. Select the FIZA repository.
5. Wait for deployment to finish.
6. Open the deployment logs.
7. Complete WhatsApp authentication.
8. Keep the service running.

💗 **That's it! FIZA is ready to go.**

---

## 🎨 Deploy on Render

1. Click **Deploy to Render** above.
2. Connect your GitHub account.
3. Select the FIZA repository.
4. Create your service.
5. Use:

**Build Command**

```bash
npm install --legacy-peer-deps
```

**Start Command**

```bash
node index.js
```

6. Deploy.
7. Open the logs.
8. Complete WhatsApp authentication.

---

## 💜 Deploy on Koyeb

1. Click **Deploy to Koyeb**.
2. Connect your GitHub repository.
3. Select the `main` branch.
4. Deploy the application.
5. Check the deployment logs.
6. Complete WhatsApp authentication.

---

## 💙 Deploy on Replit

1. Click **Run on Replit**.
2. Sign in to Replit.
3. Fork or import FIZA.
4. Open the Shell.
5. Install dependencies:

```bash
npm install --legacy-peer-deps
```

6. Start FIZA:

```bash
node index.js
```

7. Complete WhatsApp authentication.

---

## 💖 Deploy on Heroku

1. Click **Deploy to Heroku**.
2. Sign in to Heroku.
3. Create your application.
4. Deploy FIZA.
5. Open your application logs.
6. Complete WhatsApp authentication.

> 🌸 Cloud platforms can change their deployment requirements. If a one-click deployment does not work, check the platform's current documentation.

# 🖥️ VPS / Linux

<div align="center">

### 🎀 Simple VPS Installation

</div>

```bash
git clone https://github.com/FAHIM143X/fiza.git
cd fiza
npm install --legacy-peer-deps
npm install -g pm2
pm2 start index.js --name fiza
pm2 save
pm2 startup
```

💗 After running `pm2 startup`, follow the command shown by PM2 and then run:

```bash
pm2 save
```
