## ✨ What FIZA Can Do

### 🤖 AI & Intelligence
ChatGPT, Gemini, DALL-E, Bing AI, Blackbox AI, and AI image generation — all from your WhatsApp chat.

### 🎮 Games
Akinator, Tic-Tac-Toe, Rock Paper Scissors, Word Search, Love Meter, Space Galaxy, and more multiplayer fun.

### 👥 Group Management
Auto welcome/goodbye messages, anti-link protection, anti-toxic filter, anti-delete detection, mute/unmute, kick, promote, demote, polls, warnings, and tag all.

### 💝 Fun & Relationship
Find your wife, husband, crush, girlfriend, boyfriend, bestie, soulmate, or even your enemy! Plus ship compatibility, jokes, memes, quotes, and roasts.

### 📥 Downloaders
Download from YouTube (MP4/MP3), Instagram, TikTok, Twitter/X, Facebook, SoundCloud, Spotify, Google Drive, MediaFire, APKs, wallpapers, and ringtones.

### 🎨 Image & Stickers
Create stickers from images, couple profile pictures, waifu/neko images, and fun cards like jail, wasted, triggered, gay, and beautiful effects.

### 🛠️ Tools
Calculator, translator, Wikipedia, weather, crypto prices, QR generator, URL shortener, text-to-speech, IP lookup, dictionary, Shazam, speed test, and more.

### 🔐 Security
Anti-spam protection, anti-link blocking, anti-toxic filtering, anti-delete message detection, private mode, and full permission system.

### 👑 Owner Controls
Sudo system (delegate owner powers), broadcast messages, manage premium users, block/unblock, restart/shutdown, auto-read, auto-typing, and custom prefixes.

### 💖 Kawaii Theme
Every response is wrapped in beautiful pink borders with heart emojis, cherry blossoms, and cute messages — making your bot feel warm and lovable.

## 🚀 Quick Start

### Prerequisites
- **Node.js** 18+
- **FFmpeg** (for stickers & media)
- **yt-dlp** (for YouTube downloads)
- **ImageMagick** (optional, for image effects)

### Installation

```bash
git clone https://github.com/FAHIM143X/fiza.git
cd fiza
npm install --legacy-peer-deps
node index.js
